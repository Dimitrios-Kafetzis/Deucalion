# Getting started

Two short pages get you from nothing to a first backup:

1. **[Install Deucalion](install.md)**: download it and run its installer. About 5 minutes.
2. **[Your first backup](first-backup.md)**: prepare a backup drive and back up. About 15 minutes,
   plus the time it takes to copy your files.

## What you need

- A computer with **Ubuntu 24.04 or newer** (the Ubuntu Desktop, as installed from ubuntu.com). On
  Ubuntu 22.04, Deucalion works from the command line only.
- An **external drive** with enough space for your home folder: a USB hard disk or SSD. A drive
  twice the size of your home folder leaves room for old versions of files.
- An **internet connection** for the installation.
- Your **administrator password** (the password you type to log in to Ubuntu, if you are the
  computer's main user). It is needed for a few steps, and Ubuntu asks for it when needed.

!!! tip "Not sure how much space your home folder uses?"
    Open the **Files** app, right-click **Home**, and choose **Properties**. The size is shown at
    the top. Deucalion also shows the size of everything it will copy before it copies anything.

## Using the app or the terminal

Everything in Deucalion can be done in two ways:

- **The app**: a window with buttons, like other Ubuntu apps. This is the easiest way.
- **The command line**: commands you type in a *terminal* window, such as `deucalion backup`. Useful
  if you prefer typing, or on a computer without a desktop.

Every tutorial on this site shows both, in tabs. Choose the tab you want once; the other pages
remember your choice.

=== "App"

    You'll see screenshots and the names of buttons, in **bold**.

=== "Command line"

    You'll see the commands to type, and what Deucalion prints back.

### Opening a terminal (only needed for the command line)

A terminal is a window where you type commands. To open one:

1. Press ++ctrl+alt+t++. A window with a blinking cursor opens.
2. Type a command (or paste it with ++ctrl+shift+v++), then press ++enter++.

When a command asks a question, type the answer and press ++enter++. When it asks for a password,
nothing appears on screen while you type: that is normal. Type it and press ++enter++.
