# About

Open the main menu (☰, at the top of the sidebar) and choose **About Deucalion**.

![The About dialog: the Deucalion icon, the name, Dimitrios Kafetzis, the version 0.2.0, and a Details
row.](../assets/screenshots/app/about.png){ .shot }

It shows the version you are running. **Details** shows a short description and a link to the
website, [github.com/Dimitrios-Kafetzis/Deucalion](https://github.com/Dimitrios-Kafetzis/Deucalion).
From version 0.2.1, **Report an Issue** opens the page where you can report problems, and **Legal**
shows the license: Deucalion is free software under the GNU General Public License, version 3 or
later.

In a terminal, `deucalion --version` prints the version:
